# Portfolio-My-Tia-UP
MY TIA DESIRE RAZATOVONIAINA — NETLIFY PORTFOLIO

1. Go to https://app.netlify.com/
2. Sign in or create an account.
3. For the simplest deployment, drag this entire folder into Netlify Drop:
   https://app.netlify.com/drop
4. For the long-term setup, put this folder in a GitHub repository and choose:
   Add new project -> Import an existing project -> GitHub.

No build command is required for this plain HTML/CSS/JS site.

IMPORTANT:
- Replace the placeholder email link in index.html (contact@example.com) with the real address before publishing.
- Replace the placeholder LinkedIn and WhatsApp links with real URLs if desired.
